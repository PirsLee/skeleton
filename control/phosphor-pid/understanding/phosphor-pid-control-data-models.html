phosphor-pid-control / 数据模型

仅覆盖该代码库中的数据模型：配置结构体、算法状态、值/缓存、运行时实体、枚举、IPMI 线格式与对外的 D-Bus 契约。不含控制流程、线程模型与调用关系。

01模型全景与数据流向

数据从「配置文件 / entity-manager / sysfs」进入，被解析成 conf:: 系列只读配置结构体， 再与 ec:: 算法参数一起构建出运行时实体；运行时实体持有「值/缓存」模型，最终通过 D-Bus、sysfs 与 IPMI 输出。

04配置输入模型（JSON → 结构体）

config.json 的键到 C++ 结构体字段的映射。* 为解析器强制要求， ○ 为可选并给出缺省值。

sensors[]→ std::map<std::string, conf::SensorConfig>，键为 name
JSON 键类型必填默认映射 / 语义
namestring*—map 键，同时被 zone 的 inputs 引用
typestring*—fan / temp / margin
readPathstring*—决定读接口：/extsensors/ → EXTERNAL，D-Bus → DBUSPASSIVE，/sys/ → SYSFS
writePathstring○""仅 fan 使用；/sys/ → SysFsWrite*，D-Bus 路径 → DbusWrite*
minint64○0原始值下界；解析器对非 fan 类型忽略并告警
maxint64○0原始值上界；解析器对非 fan 类型忽略并告警
timeoutint64○fan 0 / 其他 2秒；0 表示不做超时检查（Sensor::getDefaultTimeout）
ignoreDbusMinMaxbool○false忽略 D-Bus 上报的 MinValue/MaxValue，只用配置值
unavailableAsFailedbool○trueAvailability=Unavailable 视作故障
ignoreFailIfHostOffbool○false主机下电期间不判定该传感器故障
zones[]→ std::map<int64_t, conf::ZoneConfig> + std::map<int64_t, conf::PIDConf>，键为 id
JSON 键类型必填默认映射 / 语义
idint64*—zone 标识，同时出现在 D-Bus 对象路径与日志文件名
minThermalOutputdouble*—ZoneConfig.minThermalOutput，热控输出下限（通常为 RPM）
failsafePercentdouble*—ZoneConfig.failsafePercent，整区失效保护百分比
cycleIntervalTimeMSuint64○100主循环周期；<1 时回退默认并告警
updateThermalsTimeMSuint64○1000热传感器刷新周期；<1 时回退默认并告警
accumulateSetPointbool○false同一传感器的多个控制器输出 PWM 累加
pidsarray*—PIDConf，键为 pid 的 name；重名会告警并覆盖
zones[].pids[]→ conf::ControllerInfo
JSON 键类型必填默认映射 / 语义
namestring*—PIDConf 键
typestring*—fan / margin / absolute / summation / stepwise
inputsstring[]*—被引用传感器名，经 spliceInputs 合并为 SensorInput[]
setpointdouble*—初始目标值
tempToMargindouble[]○空与 inputs 同序；非 0 位置开启温度→margin 转换
missingIsAcceptablestring[]○空命中名单的输入缺失时不进入失效保护
FailSafePercentdouble○0该 PID 的失效保护百分比（键名首字母大写）
pid.samplePerioddouble*—→ ts，采样周期（秒）
pid.proportionalCoeff
pid.integralCoeff
pid.feedFwdOffsetCoeff
pid.feedFwdGainCoeff		double*—P / I / 前馈偏置 / 前馈增益
pid.integralLimit_min
pid.integralLimit_max		double*—→ integralLimit.min / .max
pid.outLim_min
pid.outLim_max		double*—→ outLim.min / .max
pid.slewNeg
pid.slewPos		double*—输出变化率限幅（负 / 正）
pid.derivativeCoeffdouble○0D 项；为兼容旧配置而设为可选
pid.positiveHysteresis
pid.negativeHysteresis		double○0回差，避免在阈值附近抖动
pid.checkHysteresisWithSetpointbool○false回差比较基准用 setpoint 而非上次输入
type == "stepwise" 时改走分段模型
pid.samplePerioddouble*—→ StepwiseInfo.ts
pid.isCeilingbool*—是否作为上限包络
pid.reading.{0..19}object○NaN分段折线 X 轴，最多 20 点
pid.output.{0..19}object○NaN分段折线 Y 轴，最多 20 点
另一条输入路径：当配置文件不存在时，同一批结构体由 dbus_configuration::init() 从 entity-manager 的 xyz.openbmc_project.Configuration.Pid / Pid.Zone / Stepwise 对象填充，键名与 JSON 不完全相同但语义对应；因此 conf:: 是两份来源的统一中间模型。
