# Math

[Accumulators]()

Boost.Accumulators是Boost里一个边来数据边计算统计量的库，不需要把整批样本存下来，只要一个一个往里喂，它能增量维护内部状态，随时取出均值、方差、分位数、矩、协方差等结果。它同时包含两层东西：

- 一个通用增量计算框架

- 一套现成的统计累加器

[Decimal]()

Boost.Detail是Boost里专门解决十进制标识误差的库：它不是更高精度的double，而是把浮点数的尾数按十进制存储，严格实现IEEE 754-2008十进制浮点数标准。

[Endian]()

Boost.Endian是Boost里处理字节序的底层工具库：它能让你在写网络协议、二进制文件、跨平台共享内存时，不用再手搓移位、不用再记忆htonl/ntohl的平台差异，也不用#ifdef判断大小端。

它提供三层能力，从裸转换到类型即端序：

- 字节序转换函数

- 端序明确的缓冲区类型

- 端序明确且能直接做算数的整数类型

[Geometry]()

Boost.Geometry是Boost里的通用计算几何库：它把几何类型和几何算法彻底解耦，可以用它自带的点、线、面模型，也可以把自己的结构体适配进去，然后直接调用距离、面积、相交、包含、凸包、简化、空间索引等一大堆算法。它是纯头文件库，不需要链接，C++14起可用，设计上对标OFC简单要素规范。

[Histogram]()

Boost.Histogram是Boost里把直方图做成现代C++泛型库的那一个：不只是数一数每个区间有几个，而是支持任意维度、任意轴类型、权重填充、每个格子塞一个累加器，而且编译期能内联到接近手写循环的速度。

它的设计初衷是对标CERN ROOT和GSL的直方图，但去掉运行期多态开销，给普通业务代码也能用的友好接口。

[Interval]()

做区间算数的库。

它把传统算数从单个浮点数扩展到一个闭区间，保证所有运算的结果区间一定包含真是数学结果，这让你能严谨地控制浮点舍入误差、处理不确定输入，而不是靠经验加个epsilon

[Math]()

提供九大模块

1. 数学常数

2. 浮点工具

3. 特定宽度浮点类型

4. 统计分布

5. 特殊函数

6. 求根与函数最小化

7. 多项式与有理函数

8. 插值

9. 数值积分与微分

[Multi-Array]()

把多维数组做成泛型容器的库：可以在C++里像写A[i][j][k]一样自然地操作N维数组，同时保证内存连续、缓存友好、维度在编译期检查，而不是用vector那种每层单独分配、缓存不友好的写法。

[Multiprecision]()

是Boost里无限精度与扩展精度的基石库：当double精度不够、当uint64_t会溢出、当金融计算不能容忍任何二进制浮点误差时，它提供了一套看起来和原生类型一模一样、但精度只受内存限制的数值类型。

[Numeric Conversion]()

Boost.NumericConversion 是 Boost 里专门解决“数值类型之间安全转换”的库：它把 int → short、double → int、unsigned → signed这类日常操作里悄悄发生的溢出、截断、符号丢失全部暴露出来，让你能选择“抛异常”、“饱和钳位”、“返回默认值”或“直接 undefined behavior（和 static_cast一样快）”。

它的核心卖点是 Policy-based（策略驱动）：转换的每一步——范围检查、溢出处理、舍入方式、精度损失——都是可插拔的策略，编译期组合，零运行时开销（如果选最快策略）。

[Odeint]()

Boost.Odeint（boost::numeric::odeint）是 Boost 里求解常微分方程初值问题（IVP）的数值库：它把“微分方程右边 f(x,t)”和“数值积分算法”彻底解耦——你只写方程，选一个步进器（stepper），库负责把 x(t)一步步算出来。头文件库，C++11 起，状态可以用 std::vector、std::array、Eigen 矩阵、Boost.Multiprecision，甚至 CUDA 上的 Thrust 向量。

[Operators]()

Boost.Operators 是 Boost 里消灭运算符样板代码的库：它用 CRTP（奇异递归模板模式）让你只写一个核心运算符（比如 operator+=），自动生成配套的 +、-、!=、>等一整套运算符。写自定义数值类型、迭代器时，不用再重复造轮子。

- 物理单位库的运算符转换（如Meters+Second->Newton）

[Polygon]()

Boost.Polygon（也叫 GTL，Geometric Template Library）是 Boost 里专注“平面多边形集合运算”的库：它的主战场不是算距离、面积、包含关系这些通用几何，而是多边形之间的布尔运算（交/并/差/异或）、偏移膨胀收缩、连通性分析，以及高性能 Voronoi 图构建。核心哲学一句话——用整数坐标换数值鲁棒性。

[QVM]()

Boost.QVM（Quaternions, Vectors, Matrices）是 Boost 里专攻“静态尺寸 2/3/4 维数学”的轻量库：它不试图做完整线性代数（没有 SVD、特征值那一套），而是把游戏、图形、仿真里最高频的向量/矩阵/四元数运算做到零依赖、零开销、还能无缝接入你已有的 float3/ glm::vec3/ 裸 C 数组。

它的设计哲学和 Eigen 正好相反——运算不绑定具体类型。你不用把项目里的向量全换成 qvm::vec，而是把原有类型“注册”进 QVM，立刻获得全套运算。

[Random]()

Boost.Random 是 Boost 里“把随机数这件事彻底工程化”的库：它不只是一个 rand()的替代品，而是一套完整体系——引擎（Engine）负责产生随机比特，分布（Distribution）负责把比特塑造成你要的统计规律，种子设备（random_device）负责给引擎一个不可预测的起点。头文件库，和 C++11 <random>接口高度相似，但分布种类更丰富。

[Ratio]()

Boost.Ratio 是 Boost 里把有理数运算搬到编译期的库：它用模板元编程在编译阶段完成分数的加减乘除和比较，结果以类型的形式存在，零运行时开销。它是 C++11 std::ratio的直接前身——如果你的编译器支持 C++11，标准库的 std::ratio本质上就是它的“转正版”。

[Rational]()

Boost.Rational 是 Boost 里“精确表示分数”的基础库：它用模板类 boost::rational<T>把两个整数封装成一个自动约分的有理数，让你用 1/3而不是 0.333333做算术——永远精确，永远不丢精度。它和之前介绍的 Multiprecision::cpp_rational（任意精度）定位不同，也和 Ratio（编译期）不同，它是运行期、固定精度、零依赖的轻量方案。

[uBLAS]()

Boost.uBLAS（Basic Linear Algebra Subprograms for Boost）是 Boost 里“基础线性代数工具箱”：向量、矩阵、张量三类容器，加上 BLAS 1/2/3 级的加减、内积、矩阵乘、范数、三角求解，稠密/稀疏/结构化存储全都有，并且现在已扩展出张量（tensor）和多线性代数能力。头文件库，接口靠运算符重载写得像数学公式，底层靠表达式模板避免无意义临时对象。

它的定位很清晰：稳定、标准、能打但不极致快。不是 Eigen/Blaze 那种冲着 SIMD 和现代 HPC 极限去的库，而是 Boost 生态里“随手就能用、语义清楚、可嵌入大项目”的线性代数底座。
