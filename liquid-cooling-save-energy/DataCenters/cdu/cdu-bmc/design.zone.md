# physical 

1/2号泵：

    inlet pressure      入口压力
    outlet pressure     出口压力
    motor temperature   泵的电机温度
    bearing temperature 泵的轴承温度
    PWM value           泵的脉宽调制信号，控制转速，0-100占空比
    Power value         泵的消耗功率
    RPM value           泵的每分钟转速，反映实际转速
    Current value       泵的电流

    Input power         为泵的变频器或电机供电的电源功率
    Total power consumption 总功耗，泵组及相关设备的总耗电量
    Input voltage       每泵供电电压
    Input current       每泵供电电流
    Input herz          每泵交流电输入频率
    Phase status        三相供电的相序或健康状态
    SPD status          浪涌保护器状态，防止雷击浪涌
    VFD status          每路直接控制泵电机转速的变频器
    PSU status          为控制系统供电的直流电源模块状态

阀：

    Valve opening       阀门开度


二次侧回路：

    Coolant return pressure 1/2     二次侧回水压力
    Coolant return filter 1/2       二次侧回水过滤器压力
    Coolant supply pressure 1/2     二次侧供水压力
    Coolant return temperature 1/2  二次侧回水温度
    Coolant supply temperature 1/2  二次侧供水温度

    Differential pressure           二次侧压差
    Coolant filter differential pressure    二次侧过滤器压差

    Coolant supply flow rate        二次侧供水流量


一次侧回路：

    Water in pressure 1/2           一次侧供水压力
    Water in filter 1/2             一次侧供水过滤器压力
    Water in temperature 1/2        一次侧供水温度
    Water out pressure 1/2          一次侧回水压力
    Water out temperature 1/2       一次侧回水温度

    Water filter differential pressure  一次侧过滤器压差

    Water out flow rate             一次侧回水流量

BMC：

    BMC CPU utilization             BMC CPU使用率
    BMC mem utilization             BMC mem使用率

系统：

    Ambient temperature             环境温度      
    Dew point                       露点温度
    Ambient relative humidity       环境相对湿度

    Second level sensor 1/2/3/4     二次侧水位传感器

    Leakage 1:primary piping tray     一次侧漏液传感
    Leakage 2:secondary piping tray   二次侧管道
    Leakage 3:external tray           外部托盘
    Leakage 4:internal base tray      内部底座托盘
