# L1 物理/领域实在

**泵**

物理结构：过流单元 + 电机单元 + 电子控制单元

实际上对泵的控制：

    PLC侧看重“怎么让泵达到转速”，关心PWM+TACH电气接口
    BMC侧看重“泵现在的转速是多少、该要多少”，关心转速物理量
    泵PWM频率高控制的是转速

**阀**

阀的控制：

    开环控制
    使用的是比例阀PWM
    阀的物理量是开度
    阀PWM频率低控制的是电流（开度正比于电磁力，电磁力正比于电流），也就是改变PWM占空比->改变平均电流->改变阀开度

**物理结构解析**

1. 为什么一次侧进水路和二次侧回水路的末端加上过滤器？

    因为板式换热器式最怕堵的部件。也就是说过滤器的核心保护对象是换热器本身。

    二次侧回水从服务器回来，携带的式服务器冷板内部脱落的金属屑、焊渣等杂物。

    一次侧进水通过过滤器过滤保证进入的水无杂质（相对）。

2. 为什么阀在一次侧进水路上？泵在二次侧回水路上？且泵是双冗余的？

    阀在一次侧是调节换热量，泵在二次侧是给循环动力，泵的双冗余是为了不让IT负载在几分钟内过热。

    ```
    一次侧的本质是外部冷源分支——楼宇冷水主泵已经在推着一次侧水走了，CDU这一端不需要再自己加动力，只需要决定多少冷量进入换热器换热。

    阀的职责是调节换热量，不是调节流量动力，一次侧进入CDU后，典型会配备一个二通/三通旁通调节阀

    其控制逻辑是：

        二次侧供水温度偏高：开大阀，多放冷水流进换热器换热-->换热量上升

        二次侧供水温度偏低：关小阀，少放冷水-->换热量下降
    ```

    ```
    二次侧是贴着IT侧的环路，必须自己有动力源。

    二次回水侧通常是低压，高温侧，泵吸入条件更好。

    这样安排泵的位置的好处是：

        - 泵吸入端是板换出口的低温液，泵送介质温度更低，对密封和轴承更友好。

        - 回水侧压力通常低于供水侧，泵在低压侧吸入，高压侧排出，NPSH更容易满足。

        - 泵后就是供水主管，加压后的液体直接送向冷板，供水压力稳定。

    泵的控制逻辑：

        二次侧回水温度高：泵转速调高，加快换热

        二次侧回水温度低：泵转速调低，减缓换热

    ```

    ```
    泵坏了直接会导致二次侧宕机。

    泵故障并不是概率事件而是必然发生的事件，区别在与什么时候发生。

    双冗余泵的形态

        1+1热备         一主一备，主泵故障备泵自动接管          单台CDU内部
        N+N降容运行     两台各出一半力，任一台坏另一台出全力        高密机柜CDU
        N+1多泵并联     3台泵带2台流量，坏一台不掉性能           大流量CDU
    ```

3. 漏液传感器监测的是哪一块的？液位传感器为什么在两个泵之前各有一个，在入泵前的主路上也有一个，总共三个？

    漏液传感器：监测系统外部有没有不该出现的液体，安全类警报

    液位传感器：监测系统里还剩多少冷却液，泵会不会吸空，运行类保护

    ```
    缓冲罐/膨胀罐上的液位，代表整个二次侧系统的冷却液存量。

    作用：

        - 补液判断：液位低，启动补液泵；反之。

        - 热胀冷缩缓冲：冷却液升温体积膨胀，膨胀罐吸收多余体积，维持系统压力稳定。

        - 气液分离：把系统里析出的气泡排掉，防止气塞

        - 趋时预警：液位持续缓慢下降，疑似慢性泄漏

    每台泵前的支路液位，防止泵干转

    作用：

    - 低液位停泵：液位低于阈值 → 禁止启动/立即停该泵，防止叶轮干磨烧轴承

    - 单泵隔离维护：维护泵A时，关A支路隔离阀、排空A支路。这时液位①能确认“A支路确实排空了”，人员才能安全拆泵

    - 气阻判断：如果泵前液位波动剧烈、伴随气泡，说明系统有气，需要先排气再运行

    - 启动联锁：双泵切换时，备泵启动前先确认其入口液位正常

    入泵前的主路公共母管液位

    作用：

        - 确认罐到泵区之间的主路没有断流

        - 捕捉罐里有液体但是主路供给不上的异常

        - 作为双泵启动预警，如果这个液体位异常，那么两台泵都不应该启动，先排查异常。

    ```

4. 为什么用液体的压力、温度、流量来表征一次侧、二次侧的入水路径和回水路径？为什么用压差等参数表征泵、过滤器等部件？

    环境参数描述：系统能不能满足供冷需求

    部件参数描述：设备自己是否健康

    这些参数就是典型的表征参数。

    整个传感器布点的同一底层逻辑是：用差值消除共模干扰，把状态变化从背景值里剥离出来。

    实际上：

        温度描述 热力学状态

        流量描述 热搬运量

        压力描述 水力条件

5. 二次侧回路上的expansion tank是干什么的？

    液体热胀冷缩，吸收压力。


**物理量与控制**

实际上CDU的控制目标一般是：二次侧出水温度

**一个控制案例**

系统刚刚上电，目标温度40

BMC外PID环：

    写入2000RPM作为初始值

MCU本地PID环：收到目标2000RPM
    
    本地TACH读到1200RPM
    MCU内部速度PID：误差+800，输出占空比PWM55%
    泵转速开始上升；BMC不管。

一个节拍之后：

    MCU再次采样，转速1950,误差50,占空比微调到62%

数个节拍之后：

    MCU本地PID环：
    
        把转速稳定在1998-2002,本地闭环PID收敛。

    BMC外PID环：

        温度传感器读到40.3,比目标值略高
        BMC外PID环计算出新目标转速2300RPM
        写入MCU对应的寄存器

    MCU本地环：

        收到新目标2300,继续本地PID环，把转速平滑拉向2300

BMC侧持续监控
